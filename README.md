# HAEN HETHER: Installer

Toolkit Windows dari **HAEN KOMPUTER** untuk menyelamatkan, memindahkan, dan mengelola PC: Rescue USB, backup & restore image Windows, Boot Repair, backup driver, kesehatan disk, dan format disk.

## Unduh

**[⬇ Unduh versi terbaru](https://github.com/sa4nha-beep/haen-hether-releases/releases/latest)**

Buka halaman di atas, lalu unduh file `HAEN-HETHER-Setup-x.y.z.exe` di bagian *Assets*.

## Memasang

1. Jalankan `HAEN-HETHER-Setup-x.y.z.exe` dan ikuti wizard. Aplikasi membutuhkan hak Administrator.
2. Bila muncul **"Windows protected your PC"**, klik **More info → Run anyway**. Installer belum ditandatangani sertifikat.

## Memperbarui

Di HAEN HETHER, buka **Pengaturan → Cek pembaruan → Unduh & pasang**. Versi baru diunduh dari halaman ini dan diverifikasi SHA-256-nya. Setelah itu versi baru dipasang otomatis menimpa versi lama, lalu aplikasi terbuka kembali. Pengaturan dan riwayat backup tetap tersimpan.

Setiap rilis menyertakan `latest.json` (versi, URL, SHA-256) yang dibaca aplikasi saat memeriksa pembaruan.
